# Rat kidney aging (NORIGAMI): code and data for the proteomics and metabolomics figures

This folder holds the code and input data behind these figures of the manuscript:

- Figure 4: the deep proteome and metabolome of the aging kidney, and a protein clock.
- Figure 5: old kidneys diverge along a dominant injury-remodeling axis.
- Supplementary Figures S3–S11.

Everything runs from this folder. Inputs are read from `data/`, results are written to `outputs/`, and every location is defined once in `paths.py`.

## Quick start

```
python run_all.py                # every figure, about 1 minute
python run_all.py --with-clock   # also refit the protein clock first (about 30 minutes)
```

- Run with Python 3.12 and the packages listed under Environment.
- Each script can also be run on its own, from any working directory: `python scripts/figure5/figure5_remodeling_axis.py`.
- `run_all.py` gives the order (see Run order).

## Run order

1. **`preprocessing/metabolomics_export_to_table.py`**: instrument export → metabolite table by sample. It equals `data/metabolomics/metabolite_log2_by_sample.csv`.
2. **`preprocessing/metabolite_age_statistics.py`**: metabolite matrix and age statistics. The cohort without P64 equals `data/metabolomics/metabolite_age_statistics.csv`.
3. **`figure4/protein_clock.py`**: optional, about 30 minutes. It refits the clock into `outputs/protein_clock/`; Figure 4 reads the shipped copy in `data/proteomics/protein_clock/`.
4. **`figure4/figure4_supp_s4a_s5_s7.py`**: Figure 4, S4A, S5 and S7. It also writes the tables that Figure 5C, 5G and 5H use.
5. **`figure4/figure4f_lower_kim1_shares.py`**: the Fig 4F table.
6. **`figure5/figure5_remodeling_axis.py`**, then S3, S4, S6, S8, S9, S10 and S11. S4 needs the S4A PDF from step 4.

**Intermediate tables.** Steps 4 and 5 depend on each other. Step 4 draws Fig 4F from the table step 5 writes, and step 5 reads the Fig 4B rows and per-protein statistics step 4 writes. The figure scripts therefore read the five shipped tables in `data/intermediate/`. Rerunning steps 4 and 5 regenerates the same tables byte for byte in `outputs/`. After changing an input, copy the regenerated tables into `data/intermediate/` and run steps 4–6 again.

## Data notes

- **Protein matrix (Supplementary Table 2).**
  - File: `data/proteomics/protein_abundance_log2.csv`.
  - Content: 11,485 protein records × 31 rats, log2 relative to the mean of the seven 9-month rats, with no imputation.
  - It is byte-identical to the Supplementary Table 2 file of the manuscript (MD5 `3D164F20AC423022AC80A1D40E174243`).
  - Gene-level analyses (11,040 genes) use one representative record per gene (`selected_gene_representative` in `proteomics/protein_age_statistics.csv` and `protein_annotation.csv.gz`).
- **Metabolomics.**
  - 269 features in 32 rats. Analyses exclude rat P64 and use NAD⁺ as the log2 of its two summed peaks (`MET_ROW_0082`, `MET_ROW_0062`).
  - The two cyclic ADP-ribose features (`MET_ROW_0099`, `MET_ROW_0083`) are not analysed.
  - `metabolomics_compounds_export.xlsx` is the instrument export (Compounds sheet, normalized peak areas).
- **RNA.**
  - Kidney RNA from 54 male rats of the same colony at 6, 12, 18, 21 and 27 months (Shavlakadze et al., 2026; GEO GSE314970).
  - `kidney_rna_tmm_log2cpm.csv.gz` and `kidney_rna_samples.csv` are the deposited TMM log2-CPM data and sample table.
  - The other files in `rna_shavlakadze2026/` are the derived tables the figures read.
- **Published proteomes.**
  - Fig 4A uses the two count tables in `published_proteomes/`.
  - The study tables, gene-identity mappings, `annotations/lambert2018_human_tf_census.csv` and `annotations/functional_class_inventory.csv` are the sources of those counts.
  - Complete = an observed, finite value in every animal before any imputation. A rodent gene counts as a transcription factor only if every human member of its homology class is in the census.
- **Changes made to the copied data.** Five files differ from their originals, recorded in `data_manifest.csv`:
  - `metabolomics/animals.csv` and `metabolomics/sample_key.csv`: the tissue dry-weight and solvent-volume columns were removed.
  - `metabolomics/metabolomics_compounds_export.xlsx`: the author name and storage path in the file metadata were removed; the sheet is unchanged.
  - `published_proteomes/transcription_factor_counts_by_study.csv`: only the rows for this study and the published proteomes are kept, and the first row is relabelled.
  - `proteomics/protein_clock/run_manifest.json`: its file-path fields are relative to this folder.
  - No values used by the figures changed.

## Verification

On 28 Oct 2026 every script was run from this folder with the environment above. The results were compared with the outputs used in the manuscript:

- Byte-identical:
  - every figure PNG: Figures 4 and 5 and S3–S11, including S4A, S5 and S7;
  - every panel table: Fig 4B–D, 4F, 5G, 5H, S7A, and the per-protein statistics;
  - the number files of Figure 5, S4 and S9;
  - the metabolite tables from steps 1 and 2.
- Equal numbers: every value in `number_checks.csv` (171 values). Only the free-text `source` column differs, where three labels were reworded.
- Protein clock (`protein_clock.py`, 28 minutes): the per-fold protein rankings (`model_arrays.npz`) and the feature-selection table are byte-identical to the shipped clock. The predictions agree to within 5 × 10⁻¹⁴ months (floating-point order in parallel fitting). The shipped `cv_performance_summary.csv` has one extra column, `selected_feature_count_status`, added by a later sensitivity analysis that the figures do not use.

**Changes to the code.** Scripts were renamed and regrouped. Absolute paths were replaced by `paths.py`, output files were renamed, and comments that referred to the project's internal history were removed. In addition:

- an alternative-dataset mode that this package does not ship was removed from `figure4_supp_s4a_s5_s7.py` and `omics_data.py`;
- S8 and S10 were extracted, with their drawing code unchanged, from a larger figure module that also drew unrelated figures.

The analysis code is otherwise unchanged; the identical outputs above confirm it. `scripts_manifest.csv` lists the original file name of every script.

## Known gaps

**Not included**

- The raw PSM exports: 8 files, 605 MB in total. The script that builds the protein and peptide matrices from them is not included either, so the shipped matrices are the starting point. Its parameters are in the Methods: signal-to-noise filter, bridge-channel alignment, summed PSM signal, centring on the 9-month mean.
- Code for several derived input tables. The tables themselves are provided and their methods are described in the Methods:
  - the RNA remodeling score in the 54 RNA rats and its marker correlations;
  - the protein–RNA effect tables and the complement and basement-membrane RNA effects;
  - the proximal-tubule adjusted effects and matched control sets (S8);
  - the program membership table;
  - the coverage and transcription factor counts (Fig 4A);
  - the blood-signal scores (S11);
  - the RNA layer of the trajectory examples (S6).
- The GEO GSE314970 deposit itself, which is public. Only the kidney tables derived from it are included.

**Other limitations**

- `figure4_supp_s4a_s5_s7.py` also draws `metabolome_axis_overview.pdf`. It is not used in the paper; the same function writes the Figure 5G/H tables.
- `outputs/` contains the results of the verification run. Rerunning overwrites them.
